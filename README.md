# AstroWay

Приложение «AstroWay — сонник, гороскоп, расклады» для русскоязычной аудитории. Flutter, Android (RuStore, Google Play).

## Что уже есть
- Регистрация: имя, пол (необязательно), дата рождения (знак и возраст считаются сами), время рождения (8 интервалов или «не помню»), согласие 152-ФЗ, 16+.
- Главный экран: сцена по времени телефона (утро 06–10, день 10–17, вечер/ночь 17–06), фаза Луны, «Энергия Солнца / Настроение Луны», личный прогноз дня, переключатели «до 50 / 50+» и «Серьёзно / Легко».
- Сонник: голосовой ввод (распознавание речи Android, ru-RU) или текст, толкования по источникам, личная часть, подпись «Толкование — подсказка, а не приговор», вопрос волшебницы и память ответов.

Профиль и ответы пока хранятся только на телефоне. Перед публикацией: сервер в РФ (152-ФЗ), Pay SDK для RuStore, CloudPayments для Google Play.

## Тестовая сборка
Каждый push в `main` собирает APK: вкладка **Releases → Тестовая сборка AstroWay → AstroWay-test.apk**.
